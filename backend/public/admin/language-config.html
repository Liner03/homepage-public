🌐 语言配置

管理编程语言到 CSS 类名的映射关系，用于前台语言标签的显示

📚 使用说明

这个页面用于配置编程语言在前台的显示样式。当访客查看你的 GitHub 统计时，系统会显示你使用的主要编程语言。

💡 工作原理：
  1. GitHub API 返回语言名称（如 "JavaScript"）
  2. 系统查找对应的 CSS 类名（如 "js"）
  3. 前台显示带颜色的标签：JavaScript (24%)
🎨 CSS 类名说明：

• js - 黄色（JavaScript/Vue/React）

• py - 蓝色（Python/Java/C++/Go 等）

• ts - 蓝色（TypeScript）

• css - 紫色（CSS/HTML）

🚀 快速开始
1️⃣ 查看当前配置
向下滚动查看已配置的语言列表，系统已预设了常用语言
2️⃣ 添加新语言
在下方表单中填写语言名称和 CSS 类名，点击"添加语言"按钮
3️⃣ 编辑或删除
在语言列表中点击"编辑"修改配置，或点击"删除"移除不需要的语言

❓ 常见问题
Q: 如何知道我的 GitHub 项目使用了哪些语言？
访问你的 GitHub 主页，系统会自动从 GitHub API 获取你的语言使用统计。打开浏览器开发者工具（F12）→ Network 标签页，刷新前台页面，查找 GitHub API 请求可以看到返回的语言列表。
Q: 为什么添加了语言但前台没有显示？
请检查：
1. 语言名称是否与 GitHub API 返回的完全一致（包括大小写）
2. 刷新前台页面，清除浏览器缓存
3. 检查浏览器控制台是否有错误信息
Q: CSS 类名只能使用 js、py、ts、css 这几种吗？
目前系统预设了这几种 CSS 类名对应不同的颜色。如果需要添加新的颜色类名，需要在前台的 CSS 文件中添加对应的样式定义。建议使用现有的类名以保持统一的视觉风格。
Q: 不小心删除了配置怎么办？
点击页面底部的"重置为默认"按钮，系统会恢复所有常用语言的默认配置（JavaScript、Python、TypeScript 等18种语言）。
Q: 修改配置后需要重启服务器吗？
不需要。所有配置都是实时保存的，修改后只需刷新前台页面即可看到效果。配置数据保存在数据库中，服务器重启后仍然有效。
