📚 使用说明

这个页面用于编辑前台网站的配置文件，包括个人信息、GitHub账号、社交链接等。

⚠️ 重要提示：
• 这是 JavaScript 代码，请保持正确的语法格式
• 字符串要用引号包裹（单引号或双引号）
• 数组用方括号 [ ]，对象用花括号 { }
• 不要删除必需的字段，可以修改值
💡 常用配置项：
• PERSONAL - 个人信息（姓名、头像、座右铭）
• GITHUB_USERNAME - GitHub 用户名
• SOCIAL_LINKS - 社交媒体链接
• websites - 我的站点列表
• projects - 项目列表
🚀 快速入门指南
1️⃣ 修改个人信息
找到 PERSONAL 对象，修改 name（姓名）、title（标题）、quote（座右铭）等字段。
示例：name: "张三"
2️⃣ 设置 GitHub 用户名
找到 GITHUB_USERNAME，将其改为你的 GitHub 用户名。
示例：const GITHUB_USERNAME = "octocat";
3️⃣ 添加社交链接
在 SOCIAL_LINKS 数组中添加你的社交媒体。每个链接包含 icon（图标）和 url（链接）。
图标请参考 Font Awesome
4️⃣ 保存并预览
点击"保存配置"按钮，然后刷新前台页面查看效果。如果有错误，请检查语法是否正确。

直接在下方编辑器中修改配置，保存后刷新前台页面即可看到效果

❓ 常见问题
Q: 保存后前台没有变化怎么办？
1. 确保点击了"保存配置"按钮
2. 强制刷新前台页面（Ctrl+Shift+R 或 Cmd+Shift+R）
3. 清除浏览器缓存
Q: 保存后出现错误怎么办？
检查 JavaScript 语法是否正确：
• 字符串要用引号包裹
• 数组元素之间要用逗号分隔
• 对象的键值对用冒号连接
• 每行代码后面可能需要分号或逗号
如果不确定，点击"重置"按钮恢复原始配置
Q: 不小心删除了重要内容怎么办？
点击"重置"按钮可以恢复到上次保存的状态。如果需要恢复默认配置，请联系技术支持或查看项目文档。
